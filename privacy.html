Privacy Policy

Microstock Studio Pro — a Windows app by Rhizkit. Effective date: 15 September 2026.

Short version: Upscaling, quality-checking, metadata embedding, and CSV export all run locally on your PC. The one thing that leaves your machine is the image itself when you ask the app to generate an AI title/description/keywords — that image is sent directly to the AI provider you choose (OpenAI, Google Gemini, or OpenRouter), using an API key you supply. Rhizkit has no server, never sees your images, and never sees your API key.

What the app accesses

The app only touches files you explicitly point it at:

  • It reads the image files you add to the queue (a folder or individual files you pick).
  • It writes new, processed copies (upscaled, with embedded metadata) plus CSV export files to the output folder you choose. Your original source images are never modified, moved, or deleted.

What gets sent over the network - and to whom

Microstock Studio Pro does not operate any server of its own. The only network calls the app makes are the ones needed to generate AI title/description/keywords for an image, and only when you have quality-gated it through and the app reaches that step:

  • The (upscaled) image is sent directly from your PC to the AI provider you selected in Settings - currently OpenAI, Google Gemini, or OpenRouter - using the API key you entered yourself (bring-your-own-key). That request goes straight from your PC to that provider's own servers; it never passes through anything Rhizkit operates.
  • Handling of that image once it reaches the provider (retention, training use, etc.) is governed by that provider's own privacy policy, not this one. Check the provider you choose to configure for their current data-handling terms.
  • If you don't have a provider configured, or you never click a step that calls it, no image is ever sent anywhere.

Everything else - upscaling (bundled Real-ESRGAN), the automated quality gate (sharpness/exposure/noise checks), metadata embedding (bundled ExifTool), and CSV export - runs entirely on your PC with no network call at all.

What is stored on your PC

The app keeps a small preference file locally, under %LOCALAPPDATA%\MicrostockStudioPro\config.json (on a Microsoft Store install, this is redirected inside the app's own package data folder under %LOCALAPPDATA%\Packages\). It contains:

  • The API key(s) you enter for your chosen AI provider(s) - stored locally in plain text on your own PC, never transmitted anywhere except directly to that provider's own API endpoint as part of a request you initiate. Treat this file the same way you'd treat any file holding a credential: it's only as safe as your own PC's user account.
  • Your last-used source/output folders and processing options (upscale scale, quality-gate toggle, keyword preset, CSV export choices, etc.).
  • Optional creator name / copyright notice / priority keywords you choose to fill in for embedding into your exported images.

All of this can be cleared at any time by deleting that file, or by resetting the app from Windows Settings.

What the app does NOT do

  • It contains no analytics, telemetry, advertising, or tracking SDK of any kind.
  • It does not capture your screen, read your clipboard, or log keystrokes.
  • It does not send anything to Rhizkit. There is no Rhizkit-operated server in this app's data path at all.
  • It does not send an image anywhere unless you have configured a provider and the app reaches the AI-metadata step for that image.

Third parties

The only third parties involved are whichever AI provider(s) you personally configure in Settings - OpenAI, Google (Gemini), and/or OpenRouter. The app also relies on the Microsoft Edge WebView2 Runtime (a standard Windows component from Microsoft) to draw its interface; that component does not send anything over the network on this app's behalf. No other third party is involved.

Children

Microstock Studio Pro is a general-purpose productivity tool not directed at children and collects no information from anyone on Rhizkit's behalf, including children.

Changes to this policy
